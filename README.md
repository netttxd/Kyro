# Kyro

A client for Horizon with HUD, PvP and visual tools, a swipeable menu, themes and a drag-and-drop HUD editor.

## Features

- **HUD:** FPS, CPS, Coordinates, Speed, Clock, Day, Light, Session, Reach, TPS, Server, Ping, Keystrokes, Armor, Item counter, Potions, Kill feed, Scoreboard, Action bar, Inventory, Lyrics
- **PvP:** Hit markers, Hit color, Damage numbers, Combo, Cooldown indicator, Hitboxes, Low health glow, Gear warning, Shield
- **Visual:** Crosshair and editor, Held items, FOV control, Hurt cam, Motion blur, Color saturation, Fullbright, Clear fluids, World look, Low obstruction, Hide particles, Block outline, Item highlighter, Shulker preview, Glint color, Shiny potions, Food saturation, Item physics, TNT timer, 3D skin layers, Own nametag
- **Client:** Zoom, Freelook, Sprint, Better chat, Ping numbers
- **Capes:** Wavy capes and 25 capes, 20 of them animated
- **Themes:** 11 themes, 5 animated, Glass with adjustable blur, and custom colors

## Install

You need the [Horizon launcher](https://playhorizon.dev), opened once.

1. In the launcher, open the **Mods** page and choose **Add from GitHub**.
2. Paste `https://github.com/netttxd/Kyro`.
3. Let it build. The first build takes 10 to 30 minutes.
4. Start the game and press Right Shift.

Or download `kyro-<version>.hnmod` from [Releases](https://github.com/netttxd/Kyro/releases).

Kyro is a native mod, so it runs with full access to your computer. Only install it from this repository.

## Privacy

Lyrics is off by default. When you turn it on, Kyro reads the song playing on your computer and sends its title and artist to lrclib.net, api.betterlyrics.org and itunes.apple.com to get lyrics and cover art. On Windows it does this through a hidden PowerShell process, which keeps running until you close the game.
